[star] pacman repository

Signed Arch Linux packages for the STAR apps (STAR/FLUX, STAR/FOLD, STAR/AMP). Each package is the one attached to the app's latest GitHub release.

Download setup-star-repo.sh, read it, then run it. It adds the signing key and the repository, and installs nothing:

curl -fsSLO https://bstar.github.io/star-packages/setup-star-repo.sh
less setup-star-repo.sh
bash setup-star-repo.sh
sudo pacman -Syu starflux
